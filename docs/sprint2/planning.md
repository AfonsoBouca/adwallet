## Definition of Ready
A PBI is ready for Sprint Backlog if:
1. User story is written in Who/What/Why format
2. Acceptance criteria defined in Gherkin (Given/When/Then)
3. Mockup or wireframe provided
4. Estimated in story points
5. Team discussed and understood

## Definition of Done
A feature is done when:
1. Code committed on feature branch
2. PR opened with title and detailed description
3. At least 1 unit test per feature
4. At least 1 acceptance test per feature
5. CI/CD pipeline passes (GitHub Actions)
6. Code reviewed and approved by another team member
7. PR merged to main
8. Issue closed with "Closes #X" link
9. CHANGELOG.md updated
